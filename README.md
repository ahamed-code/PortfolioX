# 🚀 PortfolioX

A dynamic and modern developer portfolio built with **React**, **TypeScript**, **TailwindCSS**, **Framer Motion**, and **Three.js**.

Live Site: https://portfolio-x-psi.vercel.app/
---

## 🌟 Features

- 👋 Animated Role-Based Intro with Sound
- 👨‍💻 Sections: Hero, About, Skills, Projects, Achievements, Coding Profiles, Contact
- 🎮 3D Avatar powered by @react-three/fiber
- 🌌 Particle Background & Animated Gradient
- 🧠 Typewriter Effect for dynamic titles
- ✉️ EmailJS integration for contact form
- 🧭 Smooth Scroll Navigation
- 🎧 Global Audio Toggle Context
- 📱 Fully Responsive
